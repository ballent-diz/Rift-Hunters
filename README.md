# Rift Hunters

Survivor-like 2D original en vue de dessus (Godot 4.3, GDScript). Un Chasseur de Failles
et son équipe d'Échos affrontent des vagues de Corrompus et les Dévoreurs qui les guident.
Jeu solo, clavier + souris, en français et en anglais.

## Jouer
1. Installer [Godot 4.3](https://godotengine.org/download/archive/4.3-stable/) (version standard).
2. Ouvrir le dossier du projet dans Godot (le premier import prend quelques secondes), puis F5.
   En ligne de commande : `godot --path .`

Contrôles : ZQSD/WASD ou flèches · Espace Ruée · 1 2 3 Techniques · clic droit ordre de focus · Échap pause.
Manette prise en charge.
