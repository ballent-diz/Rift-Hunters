# Rift Hunters

Survivor-like 2D original en vue de dessus (Godot 4.3, GDScript). Un Chasseur de Failles
et son équipe d'Échos affrontent des vagues de Corrompus et les Dévoreurs qui les guident.
Jeu solo, clavier + souris, en français et en anglais.
