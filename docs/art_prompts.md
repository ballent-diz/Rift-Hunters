# Prompts de génération d'images

Généré par `tools/art/prompts.py` à partir de la bible graphique (`docs/ART_BIBLE.md`).

## Méthode conseillée

1. Générer d'abord une **image de référence** (personnage seul, pose de repos) avec le prompt « Référence ».
2. Générer ensuite **chaque animation séparément** (une ligne de frames par image), en donnant l'image de référence au générateur (référence de personnage / image-to-image) pour garder la même créature.
3. Déposer les images dans `assets/concepts/incoming/<identifiant>/` avec un `job.json` (modèle : `assets/concepts/incoming/README.md`), puis lancer l'import.
4. Il n'est pas nécessaire d'avoir toutes les animations : celles qui manquent peuvent réutiliser une autre ligne (`aliases`).

**Style commun (à garder dans chaque prompt)** : detailed 16-bit pixel art, crisp pixels, no anti-aliasing blur, dark 1-pixel outlines, limited palette with hue-shifted shading (cool violet shadows, warm amber highlights), main light from the top-left, thin violet rim light on the bottom-right edges, dark fantasy rift theme.

**Prompt négatif (générateurs qui l'acceptent)** : blurry, smooth gradients, painterly, 3d render, text, watermark, signature, frame borders, multiple different characters, perspective change between frames, cropped, background scenery, ground shadow.
